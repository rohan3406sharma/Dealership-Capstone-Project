# Dealership Website with Django and React

## Repository Name
`Dealership-Capstone-Project`

## Project Name
**Dealership Website – Full-Stack Application Using Django and React**

## Project Description
This capstone project is a full-stack dealership website developed using Django and React. It allows users to browse car dealerships, view dealer details, explore car makes and models, register and log in, and submit reviews for dealerships.

The application includes REST API endpoints, sentiment analysis for customer reviews, and automated CI/CD workflows using GitHub Actions. The project demonstrates frontend and backend integration, database operations, user authentication, and application deployment.

## Technologies Used
- Python and Django
- React.js
- REST APIs
- HTML and CSS
- Git and GitHub
- GitHub Actions for CI/CD

## Key Features
- User registration, login, and logout
- Browse all dealerships
- Filter dealerships by state
- View dealership details and customer reviews
- Submit dealership reviews
- Analyze review sentiment
- View car makes and models
- Deployment of the web application
